# Notes App

This is a simple Notes App built with Next.js. It allows users to create, edit, and delete notes. The app also includes user authentication.

## Features

- Create new notes
- Edit existing notes
- Delete notes
- User authentication
- Responsive design

## Technologies Used

- Next.js
- React
- TypeScript
- CSS Modules

## Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

- Node.js
- npm or yarn

### Installation

1. Clone the repo
    ```sh
    git clone https://github.com/BishalKushwar/Note-app.git
    ```
2. Install NPM packages
    ```sh
    npm install
    ```
    or
    ```sh
    yarn install
    ```

### Running the App

1. Start the development server
    ```sh
    npm run dev
    ```
    or
    ```sh
    yarn dev
    ```
2. Open your browser and navigate to `http://localhost:3000`
